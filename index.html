隐私政策

礼叙是一款本地离线的致辞与席间敬语工具。核心生成不要求注册或登录，开发者不接收、不上传用户输入。本版本不提供邀请码、邀请奖励或自建账户服务。

1. 我们处理的信息

  • 地区、场合、身份、风格、时长、饮品模式与选填的姓名、公司、学校等信息，仅用于在设备本地生成文本。
  • 收藏、历史、编辑稿与设置保存在设备本地，并可能随设备备份进入用户自己的 iCloud 或电脑备份。
  • 购买状态由 Apple StoreKit 处理。我们不接触银行卡、Apple ID 密码或完整支付信息。

2. 开发者不接收的信息

开发者不接收姓名、公司、学校、稿件、通讯录、位置、照片、麦克风、剪贴板或设备广告标识符，不进行跨应用追踪，不接入第三方广告、分析或登录 SDK，也不运营接收用户内容的服务器。上述内容仍可能由用户保存在自己的设备及其设备备份中。

3. 系统能力

  • 系统朗读：仅在用户主动点击时使用，不录音。
  • 系统分享：仅在用户主动点击“分享礼叙”或分享稿件时调起，分享内容由用户确认。
  • StoreKit：用于购买与恢复 Pro 权益。

4. 数据保存与删除

本地稿件、收藏、历史与设置可由用户在“我的 → 设置 → 清除全部本地数据”中删除；卸载应用也会删除应用容器中的这些内容。设备备份可能保留旧副本，直到用户按系统设置覆盖或删除相应备份。购买凭证由 Apple 管理，可通过“恢复购买”重新验证权益。

5. 未成年人

产品不面向未成年人饮酒场景，儿童、学生相关场景自动使用无饮品表达。我们倡导文明表达、量力而行、请勿劝酒。

6. 联系我们

如对隐私政策有疑问，请发送邮件至 sjnyu520@gmail.com。

支持中心

礼叙致辞助手 · 支持

礼叙在设备本地生成开场致辞、收尾答谢与席间敬语。无需登录，不上传姓名与稿件。

常见问题

  • 免费版可以做什么？ 每日可新生成 3 次，使用 30 个场景、地区素材、席间急救、知识库、收藏与历史。
  • Pro 是什么？ 一次性买断的非消耗型项目，不是订阅，不自动续费。解锁无限生成、PDF 导出、无水印高清海报与后续新增场景。
  • 如何恢复购买？ 打开“我的 → 礼叙 Pro”，点击“恢复购买”。请使用购买时的同一 Apple ID。
  • 免费额度怎么计算？ 免费用户每天可新生成 3 次，额度按自然日重置；即使 App 保持打开，跨日后也会自动恢复。升级 Pro 后可无限生成。
  • 如何删除数据？ 打开“我的 → 设置 → 清除全部本地数据”，即可删除稿件、收藏、历史与偏好设置。
  • 为什么没有请求权限？ 生成、历史与设置均在本地完成，仅在主动使用朗读、分享或购买时调用系统能力。
